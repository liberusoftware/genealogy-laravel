# Liberu Genealogy theme

The dedicated public theme for Liberu Genealogy uses the old branch's warm, editorial landing-page direction and adds a family-tree motif, clearer hierarchy, responsive layouts, reduced-motion support, and accessible focus states.

The landing page reads `PREMIUM_ENABLED` at render time. Open-source mode is described as open and free to use; SaaS mode is described as a seven-day Premium trial with the configured monthly and yearly prices. It never calls a Premium deployment free.

The project link is [github.com/liberusoftware/genealogy-laravel](https://github.com/liberusoftware/genealogy-laravel).
