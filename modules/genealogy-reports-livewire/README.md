# Genealogy Reports livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-genealogy-reports`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-reports-livewire`
- Installer name: `genealogy-reports-livewire`
- Package type: `liberu-module`
