# Genealogy GenealogyCore filament

This package is the one-to-one **filament** presentation adapter for `liberusoftware/module-genealogy-core`.

It owns only filament transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-core-filament`
- Installer name: `genealogy-core-filament`
- Package type: `liberu-module`
