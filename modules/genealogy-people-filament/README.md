# Genealogy People filament

This package is the one-to-one **filament** presentation adapter for `liberusoftware/module-genealogy-people`.

It owns only filament transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-people-filament`
- Installer name: `genealogy-people-filament`
- Package type: `liberu-module`
