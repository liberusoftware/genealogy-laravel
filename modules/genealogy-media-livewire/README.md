# Genealogy Media livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-genealogy-media`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-media-livewire`
- Installer name: `genealogy-media-livewire`
- Package type: `liberu-module`
