# Genealogy GenealogyCore livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-genealogy-core`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-core-livewire`
- Installer name: `genealogy-core-livewire`
- Package type: `liberu-module`
