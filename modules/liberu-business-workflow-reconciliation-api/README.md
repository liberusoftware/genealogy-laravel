# Liberu BusinessWorkflowReconciliation api

This package is the one-to-one **api** presentation adapter for `liberusoftware/module-liberu-business-workflow-reconciliation`.

It owns only api transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-business-workflow-reconciliation-api`
- Installer name: `liberu-business-workflow-reconciliation-api`
- Package type: `liberu-module`
