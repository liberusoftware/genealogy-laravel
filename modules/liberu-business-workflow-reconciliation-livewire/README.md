# Liberu BusinessWorkflowReconciliation livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-liberu-business-workflow-reconciliation`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-business-workflow-reconciliation-livewire`
- Installer name: `liberu-business-workflow-reconciliation-livewire`
- Package type: `liberu-module`
