# Liberu BusinessWorkflowReconciliation filament

This package is the one-to-one **filament** presentation adapter for `liberusoftware/module-liberu-business-workflow-reconciliation`.

It owns only filament transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-business-workflow-reconciliation-filament`
- Installer name: `liberu-business-workflow-reconciliation-filament`
- Package type: `liberu-module`
