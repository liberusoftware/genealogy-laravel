# Genealogy Timeline api

This package is the one-to-one **api** presentation adapter for `liberusoftware/module-genealogy-timeline`.

It owns only api transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-timeline-api`
- Installer name: `genealogy-timeline-api`
- Package type: `liberu-module`
