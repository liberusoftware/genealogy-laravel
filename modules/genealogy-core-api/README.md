# Genealogy GenealogyCore api

This package is the one-to-one **api** presentation adapter for `liberusoftware/module-genealogy-core`.

It owns only api transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-core-api`
- Installer name: `genealogy-core-api`
- Package type: `liberu-module`
