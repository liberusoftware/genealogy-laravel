# Liberu PlatformOrchestration filament

This package is the one-to-one **filament** presentation adapter for `liberusoftware/module-liberu-platform-orchestration`.

It owns only filament transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-platform-orchestration-filament`
- Installer name: `liberu-platform-orchestration-filament`
- Package type: `liberu-module`
