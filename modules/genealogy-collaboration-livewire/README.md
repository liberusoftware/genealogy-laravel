# Genealogy Collaboration livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-genealogy-collaboration`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-collaboration-livewire`
- Installer name: `genealogy-collaboration-livewire`
- Package type: `liberu-module`
