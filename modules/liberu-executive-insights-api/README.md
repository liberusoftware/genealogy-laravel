# Liberu ExecutiveInsights api

This package is the one-to-one **api** presentation adapter for `liberusoftware/module-liberu-executive-insights`.

It owns only api transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-executive-insights-api`
- Installer name: `liberu-executive-insights-api`
- Package type: `liberu-module`
