# Genealogy Discovery api

This package is the one-to-one **api** presentation adapter for `liberusoftware/module-genealogy-discovery`.

It owns only api transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-discovery-api`
- Installer name: `genealogy-discovery-api`
- Package type: `liberu-module`
