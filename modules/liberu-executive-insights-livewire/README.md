# Liberu ExecutiveInsights livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-liberu-executive-insights`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-executive-insights-livewire`
- Installer name: `liberu-executive-insights-livewire`
- Package type: `liberu-module`
