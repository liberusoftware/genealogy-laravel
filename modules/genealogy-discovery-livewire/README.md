# Genealogy Discovery livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/module-genealogy-discovery`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-genealogy-discovery-livewire`
- Installer name: `genealogy-discovery-livewire`
- Package type: `liberu-module`
