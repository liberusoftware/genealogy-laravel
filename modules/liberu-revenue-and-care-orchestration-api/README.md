# Liberu RevenueAndCareOrchestration api

This package is the one-to-one **api** presentation adapter for `liberusoftware/module-liberu-revenue-and-care-orchestration`.

It owns only api transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-revenue-and-care-orchestration-api`
- Installer name: `liberu-revenue-and-care-orchestration-api`
- Package type: `liberu-module`
