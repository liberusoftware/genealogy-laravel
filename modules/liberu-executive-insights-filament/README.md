# Liberu ExecutiveInsights filament

This package is the one-to-one **filament** presentation adapter for `liberusoftware/module-liberu-executive-insights`.

It owns only filament transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/module-liberu-executive-insights-filament`
- Installer name: `liberu-executive-insights-filament`
- Package type: `liberu-module`
